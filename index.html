CostTrace: what did that deploy actually cost?

Cloud bills show up a month late, as one big number. CostTrace reads a company's own billing export and ties measured cost back to the deploys and pull requests that changed it, with an honest ± range on every figure.

  • Built on the FinOps FOCUS standard, so one engine reads AWS, Azure, Google Cloud and Oracle Cloud bills.
  • A GitHub Action comments the measured cost of each pull request a day or two after it ships.
  • costtrace explain answers "why did the bill change this month?", service by service.
  • An MCP server lets AI coding agents ask what a change cost and trace it to the code behind it.
  • Local-first: billing data never leaves the customer's environment. It says "coincides with", never "caused".
